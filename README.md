# ArteMadera – Generator Wieńcowy

Wtyczka SketchUp 2023: z narysowanego obrysu domu (lico zewnętrzne), osi ścian działowych i linii kontrforów tworzy
ściany z bali 44 mm z zamkami narożnymi, kontrforami, stykami na mijankę i otworami. Każdy bal to komponent z
wycięciami i atrybutami dla wtyczki ArteMadera Dokumentacja 2D.

- Instalacja: Rozszerzenia → Menedżer rozszerzeń → Zainstaluj rozszerzenie → `arte_madera_generator_wiencowy_1.0.0.rbz`.
- Użycie: zaznacz linie → Rozszerzenia → ArteMadera Generator Wieńcowy → Generuj dom…
- Dokumentacja: `docs/specyfikacja.md`, stan prac: `docs/stan_prac.md`, mapa kodu: `docs/SPIS_TRESCI.md`.
- Testy: `bash testy/uruchom.sh`.
